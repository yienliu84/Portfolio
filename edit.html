Publish your changes

Publishing saves your text, photos, videos, and captions to GitHub and updates the portfolio for everyone.

Set up publishing access

Create a fine-grained GitHub token ↗. Set Resource owner to yienliu84, choose Only select repositories, and select Portfolio. Under Repository permissions, set Contents to Read and write. Paste the token below when publishing. It is sent only to GitHub, kept out of saved drafts, and cleared after the attempt.

Only a GitHub account with write access to this repository can publish.

Publish through the GitHub website instead

Copy the updated file, open GitHub's editor, replace its contents, and choose Commit changes.
